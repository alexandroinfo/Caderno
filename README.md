# 📖 6. Miniguia de estudo

## 6.1 O que é análise de dados?

Análise de dados é o processo de examinar, transformar e interpretar dados com o objetivo de identificar informações relevantes e apoiar a tomada de decisões.

Um processo de análise pode envolver:

1. Coleta dos dados;
2. Organização;
3. Limpeza;
4. Transformação;
5. Modelagem;
6. Análise;
7. Visualização;
8. Interpretação;
9. Tomada de decisão.

---

# 🗄️ 6.2 Fundamentos de SQL

SQL é uma linguagem utilizada para trabalhar com bancos de dados relacionais.

Entre os comandos mais importantes estão:

### SELECT

Utilizado para consultar dados.

```sql
SELECT nome, salario
FROM funcionarios;
```

### WHERE

Utilizado para aplicar filtros.

```sql
SELECT *
FROM funcionarios
WHERE salario > 5000;
```

### ORDER BY

Utilizado para ordenar os resultados.

```sql
SELECT *
FROM funcionarios
ORDER BY salario DESC;
```

### GROUP BY

Utilizado para agrupar informações.

```sql
SELECT departamento, COUNT(*)
FROM funcionarios
GROUP BY departamento;
```

### JOIN

Utilizado para relacionar informações de diferentes tabelas.

```sql
SELECT clientes.nome, pedidos.valor
FROM clientes
JOIN pedidos
    ON clientes.id = pedidos.cliente_id;
```

# 🧩 6.3 Modelagem de dados

A modelagem de dados busca organizar as informações de forma estruturada, permitindo que sejam armazenadas, consultadas e analisadas de maneira eficiente.

Um conceito importante para Business Intelligence é o **modelo dimensional**.

### Modelo estrela

É composto normalmente por:

* Uma tabela fato;
* Diversas tabelas dimensão.

Exemplo:

```text
              DIM_CLIENTE
                   |
                   |
DIM_PRODUTO — FATO_VENDAS — DIM_TEMPO
                   |
                   |
              DIM_LOJA
```

A tabela fato normalmente contém medidas e chaves relacionadas às dimensões.

---

# 📊 6.4 Power BI

O Power BI é uma plataforma utilizada para análise e visualização de dados.

Um fluxo típico pode envolver:

```text
Fonte de dados
      ↓
Power Query
      ↓
Tratamento dos dados
      ↓
Modelagem
      ↓
Medidas / DAX
      ↓
Visualizações
      ↓
Dashboard
      ↓
Análise
```

O Power Query pode ser utilizado para preparação e transformação dos dados.

O modelo de dados organiza os relacionamentos entre as tabelas.

A linguagem DAX pode ser utilizada para criação de medidas e cálculos.

As visualizações permitem apresentar os resultados de maneira mais compreensível.

---

# 🔗 6.5 Relação entre SQL e Power BI

SQL e Power BI podem trabalhar juntos em um processo de análise de dados.

Um exemplo seria:

```text
Banco de dados
      ↓
      SQL
      ↓
Consulta e preparação
      ↓
    Power BI
      ↓
Modelagem
      ↓
     DAX
      ↓
Dashboard
      ↓
Tomada de decisão
```

Nesse cenário, SQL pode ser utilizado para consultar e manipular dados enquanto o Power BI pode ser utilizado para modelar, analisar e apresentar essas informações.

# 📘 7. Glossário

| Conceito                  | Definição                                                                                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| **SQL**                   | Linguagem utilizada para trabalhar com bancos de dados relacionais.                                       |
| **Banco de dados**        | Sistema estruturado para armazenamento e gerenciamento de informações.                                    |
| **Tabela**                | Estrutura composta por linhas e colunas utilizada para armazenar dados.                                   |
| **Query**                 | Consulta realizada em uma fonte de dados.                                                                 |
| **JOIN**                  | Operação utilizada para relacionar tabelas.                                                               |
| **Primary Key**           | Campo utilizado para identificar unicamente um registro.                                                  |
| **Foreign Key**           | Campo utilizado para estabelecer relacionamento com outra tabela.                                         |
| **Modelagem de dados**    | Processo de organização e estruturação dos dados.                                                         |
| **Tabela fato**           | Tabela que normalmente armazena eventos, medidas e chaves dimensionais.                                   |
| **Dimensão**              | Estrutura utilizada para fornecer contexto aos dados.                                                     |
| **Modelo estrela**        | Modelo dimensional composto por uma tabela fato relacionada a dimensões.                                  |
| **Power BI**              | Plataforma de análise e visualização de dados da Microsoft.                                               |
| **Power Query**           | Ferramenta utilizada para importar, transformar e preparar dados.                                         |
| **DAX**                   | Linguagem utilizada para cálculos e medidas em modelos de dados do Power BI.                              |
| **Dashboard**             | Painel visual utilizado para apresentar informações e indicadores.                                        |
| **Business Intelligence** | Conjunto de processos e tecnologias utilizados para transformar dados em informações úteis para decisões. |
